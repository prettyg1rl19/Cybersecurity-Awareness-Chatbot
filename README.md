# Cyber Security Awareness Chat bot Console App 🤖

Welcome to the Cyber Security awareness chatbot - SentinelX! 
He's here to help you with everything you need to know about cybersecurity awareness! 
This is a small ***C# console application*** that makes use of **Speech Synthesis** and **user input** to anwser all of your questions!

---

  ## How to access him: 👩‍💻

### Open the GitHub link 🔗
- Kindly open the github link provided in the Word Document.
- Then, copy the link displayed in your browser by highlighting it and pressing *"Ctrl + C"* simultaneously

### Open Visual Studio Code 😶‍🌫️
- Open Visual Studio Code 2022 Community on your laptop/computer

### Add the program to VSC 😎🔎
- Select the option *"Clone a repository"*
  - ![Image](https://github.com/user-attachments/assets/f7c1ff33-f02e-4c1f-a069-58ce5942e8a0)
- Once the screen opens, paste the GitHub link into the *"Repository location"*
  - ![Image](https://github.com/user-attachments/assets/51953d8d-8a6d-4d02-82d3-2c04d23648e4)
- Then, select the path for where you's like to store the project.
  -![Image](https://github.com/user-attachments/assets/6a267ba6-e9d3-488a-a518-41cb1da9645c)
- And press *"Clone"*

***Almost there!***

## And there you have SentielX at your service! ❤️🤖

### Here are the types of questions you can ask him ✍🏻
- password
- safe browsing
- phishing
- let me ask you something
- tell me something interesting

### What makes him unique 👀
- He has sentient detection, meaning he detecta your feelings when you use keywords like "sad", "happy", "uncertain", etc!
- He remembers when you say you like something! 
- He can pick up keywords! If you say "tell me about passwords", he'll identify the keyword "password", and react in kind!
